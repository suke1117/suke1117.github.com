# 筋トレメニュー ジェネレーター

悩みを文章で書くだけで、ジムで今日からやる筋トレメニューを組み立てるWebアプリです。
種目・セット数・回数・休憩時間・1日の所要時間まで入った1週間分のプランを出力します。

ブラウザの中だけで動くので、サーバーもAPIキーも不要です。入力内容はどこにも送信されません。
GitHub Pages にそのまま置けます。

## できること

### メニューを組み立てる

- **悩みの自由記述を解析** — 「肩こりがひどい」「お腹を引っ込めたい」などの文章からキーワードを拾い、目的タグに変換します
- **入力しながら結果が見える** — 打ち込んだそばから、読み取った目的がタグで表示されます
- **条件に合わせた組み立て** — トレーニング歴 / 週の回数 / 1回の時間 / 使える器具（フルジム・マシン・ダンベル・自重）を反映
- **痛みのある部位を除外** — 腰・膝・肩を選ぶと、その部位に負担の大きい種目を候補から外します
- **分割の自動選択** — 週1回の全身トレから、週5回のプッシュ／プル／脚まで、回数に応じて分割を変えます
- **負荷設定の自動切り替え** — 筋力重視 / 筋肥大 / 脂肪燃焼 / コンディション重視 / フォーム習得の5パターン

### ジムで使う

- **DAYごとのタブ表示** — その日のメニューだけを表示。矢印キーでも切り替えられます
- **チェックと進捗バー** — 終わった種目をタップで消し込み。残り何種目かがひと目で分かります
- **休憩タイマー** — 種目ごとの休憩秒数をワンタップで計測。終了時に音とバイブで知らせます
- **種目の差し替え** — 使いたい器具が空いていないときは、同じ条件を満たす別の種目に入れ替えられます
- **プランの自動保存** — 差し替えやチェックも含め、次に開いたときそのまま続きから使えます

### 見て判断する

- **週の部位別セット数グラフ** — メイン種目の合計セット数を部位別に表示。狙った部位に厚みが出ているか、抜けている部位はないかを確認できます
- **ライト / ダーク / 自動のテーマ切り替え**
- **テキストコピー・印刷（全日まとめてPDF保存）**

## 使い方

`index.html` を開くだけです。ビルドもインストールも不要です。

```bash
# ローカルで見る場合
npx http-server .   # または python3 -m http.server
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で公開ブランチを指定してください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入力フォームと結果の表示領域 |
| `assets/style.css` | デザイントークンと全スタイル（ライト／ダーク／印刷） |
| `assets/data.js` | 種目データベース（`EX_DB`）と悩みの解析ルール（`CONCERN_RULES`） |
| `assets/app.js` | 解析・メニュー生成・描画・UIの操作 |

## 仕組み

1. **解析** — 自由記述とチェックした悩みを `CONCERN_RULES` のキーワードと照合し、目的タグ（例: `fatloss`, `posture`, `glutes`）に点数をつけます
2. **方針決定** — 点数の高い目的と痛みの有無から、セット数・回数・休憩時間の方針を決めます
3. **分割決定** — 週の回数とトレーニング歴から、その週の分割（全身 / 上下 / プッシュ・プル・脚）を選びます
4. **種目選択** — 各日の動作パターン（スクワット・ヒンジ・押す・引く・体幹など）ごとに、器具・レベル・禁忌の条件を満たす候補から点数の高いものを選びます。同じ種目が週の中で偏らないようペナルティをかけ、1回の時間に収まるまで種目を足していきます

## UIについて

- 配色は `assets/style.css` 冒頭の CSS 変数にまとまっています。`--brand`（ライム）と `--sel`（選択色）を差し替えれば全体の印象が変わります
- ダークモードは自動反転ではなく、ライトとは別に値を指定しています
- グラフの色はコントラストと明度の基準を満たす値を選んでいます（単色・直接ラベル付き）
- アニメーションは `prefers-reduced-motion` を尊重して無効化されます

## カスタマイズ

- **種目を追加する** — `assets/data.js` の `EX_DB` に1行足すだけです

  ```js
  { id:'ex_id', name:'種目名', pattern:'push_h', equip:['full','dumbbell'],
    goals:['chest','hypertrophy'], level:2, avoid:['shoulder'], note:'フォームのコツ' }
  ```

- **読み取るキーワードを増やす** — `CONCERN_RULES` の該当ルールの `kw` に単語を追加します

## 注意

このアプリが出力するのは一般的な運動情報です。診断・治療に代わるものではありません。
痛みのある方、持病のある方、リハビリ中の方は、医師・理学療法士の指示を優先してください。
