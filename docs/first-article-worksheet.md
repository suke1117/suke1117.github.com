# 1本目の記事を作るワークシート

[genre-candidates.md](genre-candidates.md) で1本目に選んだ **A-2 モニターライト** を例に、
STEP2 を実際に回す手順を書き下ろしたものです。他のジャンルでも同じ手順で使えます。

かかる時間の目安は、集める作業が20分、Claudeが40分、`own_note` を書くのが10分です。

---

## 1. 集めるもの（20分）

Amazonで「モニターライト」を検索して、**比べる商品を3〜5個**選びます。
選ぶときの条件は3つ。

- 価格帯が近いこと（3,000〜15,000円の中で、上下2倍まで）
- レビューが50件以上あること（不満の傾向が読めないため）
- **少なくとも1つは自分が実際に使ったことがある商品を入れること**

商品ごとに、次をメモしておきます。

```
商品名：
ASIN：（商品ページURLの /dp/XXXXXXXXXX の部分）
価格：
仕様：対応する上枠の厚み◯mm / 色温度◯K〜◯K / 明るさ◯lx / 電源◯

★4〜5のレビュー3件：（コピペでよい）
★1〜2のレビュー3件：（ここがいちばん重要。不満の共通点が記事の中身になる）
```

低い評価のレビューは、**並べ替えで「低評価順」にすると集めやすい**です。
「配送が遅かった」のような商品と関係ないものは飛ばして、
商品そのものへの不満だけを拾ってください。

---

## 2. Claudeに投げる（40分）

[prompts/02-comparison-article.md](prompts/02-comparison-article.md) のプロンプトの
`[  ]` を埋めて投げます。この記事の場合は次のようになります。

```
ジャンル：モニターライト（モニター掛け式のデスクライト）
狙うキーワード：モニターライト 映り込み
想定読者：夜に部屋を暗くして作業していて目が疲れる。普通のデスクライトだと
　　　　　画面に映り込むし、机も狭くなる。取り付けられるか不安もある。
比べる商品：（1で集めた3〜5個を、商品名・ASIN・価格・仕様つきで貼る）
```

レビューは `---レビュー---` から `---ここまで---` の間に貼ります。

出力される2つのYAMLブロックを、それぞれ
`data/products.yml` と `data/comparisons.yml` の末尾に追記してください。

### この記事で使う比較表の列

`table_columns` は3つまでにしてください（Pinterest画像に載る列数の上限です）。
このジャンルなら次の3つが数値で比べられます。

```yaml
table_columns: ["対応厚み", "色温度", "明るさ"]
```

`products.yml` 側の `specs` のキーも、この3つと完全に一致させてください。

```yaml
  specs:
    対応厚み: "10〜30mm"
    色温度: "2700〜6500K"
    明るさ: "1000lx"
```

## 3. own_note を書く（10分）

**ここだけは自分で書きます。** 空か雛形のままだと `validate.py` がエラーで公開を止めます。

実際に使った商品について、1〜3行。書くのは「レビューを読んでも分からないこと」です。

- 実際に測った数値 —「うちのモニターは上枠19mmで、対応範囲の下限ぎりぎりだった」
- 予想と違ったこと —「明るさより、色温度を下げたほうが目の疲れに効いた」
- 買う前に確認すべきだったこと —「湾曲モニターだと接地が2点になって不安定」

使ったことがない商品には書かないでください。
その商品は `items` から外すか、比較表だけに載せて解説から外します。

---

## 4. 確認して公開（5分）

```bash
python scripts/validate.py           # 型と表現のチェック
python scripts/build_site.py --local # 生成
python -m http.server -d public 8000 # http://localhost:8000/compare/<slug>/
```

見るのは3か所です。

1. **比較表の列が揃っているか** — `-` が並んでいたら `specs` のキーが一致していません
2. **リンクの位置** — 選ぶ基準のセクションにリンクが無いこと
3. **own_note の枠** — 「使ってみて」の枠が出ていること（出ていなければ雛形のままです）

問題なければ push すると、Actions がビルドして公開します。

```bash
git add data/ && git commit -m "add: モニターライトの比較記事" && git push
```

## よくあるつまずき

| 症状 | 原因 |
| --- | --- |
| `validate.py` が own_note でエラー | 仕様です。実際に使った一言を書いてください |
| 比較表が `-` だらけ | `specs` のキーと `table_columns` が一致していない |
| `criteria は3つ必要です` | STEP2 のプロンプトで基準が2つ以下しか返ってきている。3つ目を自分で足す |
| 記事のURLが404 | `slug` に日本語や記号が入っている。英数字とハイフンのみにする |
| CSSが当たらない | `--local` を付け忘れている |
