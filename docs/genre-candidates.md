# ジャンル候補（STEP1の実行結果）

[`prompts/01-genre-research.md`](prompts/01-genre-research.md) のプロンプトを実行した結果です。

条件は「数値やサイズで比べられる」「型番が変わりにくい」「比較記事が少ない」
「3,000〜15,000円」「効果効能を語らなくていい」の5つ。
報酬額ではなく、**繰り返し検索されること**を優先しています。

3つのクラスタに分けてあります。**同じクラスタ内は回遊がつながる**ので、
バラバラのジャンルを1本ずつ書くより、1クラスタを固めて取るほうが効きます。

## クラスタA：デスク環境（在宅ワーク）

読者の状態が「机まわりを整えている最中」で共通するため、回遊が最も作りやすい塊です。

### A-1. モニター台（モニタースタンド）

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `モニター台 高さ` / `モニタースタンド 木製 おすすめ` / `モニター台 引き出し付き` |
| 悩みの場面 | 画面が低くて首が前に出る。机の上がキーボードと書類で埋まっている |
| 比較基準 | ①天板の高さ（8cm/10cm/12cm）②耐荷重（kg）③下に入るキーボードの高さ |
| 外すべき人 | モニターアームを検討している人（そちらのほうが自由度が高い） |
| 次に困ること | 台に載せたら画面が明るすぎる → **A-2 モニターライト** |

### A-2. モニターライト（掛け式デスクライト）

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `モニターライト 映り込み` / `デスクライト 目が疲れる` / `モニターライト 取り付けられない` |
| 悩みの場面 | 夜に部屋を暗くして作業すると目が疲れる。普通のライトは画面に映り込む |
| 比較基準 | ①対応するモニター上枠の厚み（mm）②色温度の範囲（K）③明るさ（lx／照射距離） |
| 外すべき人 | 曲面モニター・上枠が極端に薄いモニターを使っている人（固定できない） |
| 次に困ること | 手元は明るくなったが、手首が痛い → **A-3 リストレスト** |

### A-3. リストレスト（パームレスト）

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `リストレスト 高さ 合わない` / `パームレスト 木製 樹脂` / `リストレスト 疲れる` |
| 悩みの場面 | キーボードを打つと手首が反る。既製品を買ったが高さが合わなかった |
| 比較基準 | ①高さ（mm。キーボードの手前高と合わせる）②素材（低反発/木/樹脂）③幅（キーボード幅と合うか） |
| 外すべき人 | 薄型キーボード（高さ15mm以下）を使っている人（不要なことが多い） |
| 次に困ること | 手首は治ったが、足が浮く → **A-4 フットレスト** |

### A-4. フットレスト

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `フットレスト 足が浮く` / `フットレスト 高さ調整` / `デスク 足置き 疲れない` |
| 悩みの場面 | 椅子を上げると足が床につかない。足を組む癖が直らない |
| 比較基準 | ①高さと角度が変えられるか ②奥行き（cm）③滑り止めの有無 |
| 外すべき人 | 昇降デスクを使っている人（立ち作業で解決することが多い） |
| 次に困ること | 足元を整えたら、ケーブルが邪魔になった → **A-5 ケーブルトレー** |

### A-5. デスク下ケーブルトレー

| 項目 | 内容 |
| --- | --- |

| 外すべき人 | 天板が薄い／ガラス天板の机を使っている人（クランプが使えない） |
| 次に困ること | 机まわりが片付いたら、座り続けることによる腰 → **クラスタA外：クッション** |

## クラスタB：賃貸の収納

「穴を開けられない」という制約が全ジャンル共通で、それ自体が検索の入口になります。

### B-1. 突っ張り棚・突っ張り棒（強度で選ぶ）

| --- | --- |

| 外すべき人 | 石膏ボードに直接突っ張ろうとしている人（下地がないと落ちます） |

## 最初に書く3本

クラスタAから始めるのを勧めます。理由は3つ。

1. **単価が比較的高い**（モニター台・モニターライトは5,000〜15,000円）
2. **回遊が5本ぶん一直線につながる**（台 → ライト → リストレスト → フットレスト → ケーブルトレー）
3. **買った人が「もう1つ」を買いやすい**（デスク環境は連鎖する）

| 順番 | ジャンル | 理由 |
| --- | --- | --- |
| 1本目 | A-2 モニターライト | 検索の悩みが具体的（映り込み・取り付けられない）で、比較基準が数値で書ける |
| 2本目 | A-1 モニター台 | 1本目からの回遊先になる。耐荷重と高さで比較表が作りやすい |
| 3本目 | A-5 ケーブルトレー | 天板の厚みという明確な失敗ポイントがあり、記事の価値が出しやすい |

3本書いたら、STEP4 のプロンプトで相互に回遊をつなぎます。

## 選ぶときの注意

- **自分が実際に買ったことがあるジャンルを優先してください。** `own_note` が書けないジャンルは、
  `scripts/validate.py` がエラーで公開を止めます（これは意図的な仕様です）
- クラスタをまたいで1本ずつ書くと、回遊が作れません。1クラスタを固めて取ってください
- 上のキーワードは候補です。実際の検索需要は Google キーワードプランナーや
  ラッコキーワードなどで確認してから決めてください
