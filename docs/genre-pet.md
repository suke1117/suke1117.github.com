# ペット用品クラスタ（STEP1の実行結果）

[prompts/01-genre-research.md](prompts/01-genre-research.md) を、ペット用品に絞って実行した結果です。

このクラスタを選んだ理由は3つ。

1. **比較の軸がすべて数値化できる**（容量・dB・部品点数・交換頻度・g単位）のに、
   それを揃えて比べた記事がほとんどない
2. **消耗品のリピートがある**。フィルター・猫砂・シートは繰り返し買われる
3. **飼い主は同じ悩みで何度も検索する**。1度書いた記事が半年後にまた読まれる

猫向けを主軸にしています。犬より単価が安定していて、室内飼いの割合が高く、
「掃除・手入れ」の悩みが具体的に言語化されているためです。

---

## 回遊の順路

飼い始めからの時間軸に沿って並べると、記事どうしが自然につながります。

```
給水（P-1）→ 給餌（P-2）→ トイレ本体（P-3）→ 猫砂（P-4）→ 見守り（P-5）→ 爪とぎ（P-6）
                ↑                                              ↓
                └──────── 留守にする日の準備 ←──────────────────┘
```

---

### P-1. 自動給水器（循環式）

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `自動給水器 猫 手入れ` / `猫 給水器 うるさい` / `猫 給水器 洗いやすい` |
| 悩みの場面 | 毎日の水替えが面倒で買ったのに、掃除の手間が増えた。ポンプの音が気になる |
| 比較基準 | ①分解して洗える部品の数（点）②フィルターの交換頻度と年間コスト（円）③動作音（dB） |
| 外すべき人 | 多頭飼いで1日2L以上飲む家庭（容量が足りません） |
| 次に困ること | 水は解決したが、留守中の食事 → **P-2 自動給餌器** |
| 単価 | 3,000〜8,000円 |

**1本目に勧めます。** 「手入れ」という不満が最も言語化されていて、
分解部品の数という数値がそのまま答えになるのに、それを揃えた記事がありません。

### P-2. 自動給餌器

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `自動給餌器 猫 停電` / `自動給餌器 詰まる` / `自動給餌器 1日 何回` |
| 悩みの場面 | 留守中の食事を任せたいが、詰まったり停電したときが不安 |
| 比較基準 | ①停電時のバックアップ（電池の有無・持続時間）②1回あたりの最小給餌量（g）③タンクの分解洗浄可否 |
| 外すべき人 | ウェットフードを与えている人（乾燥フード専用の製品がほとんどです） |
| 次に困ること | 食事が回ったら、次は排泄の掃除 → **P-3 猫トイレ** |
| 単価 | 5,000〜15,000円 |

### P-3. 猫トイレ（本体）

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `猫トイレ 砂 飛び散る` / `猫トイレ 大型 サイズ` / `猫トイレ 掃除 楽` |
| 悩みの場面 | 砂が周囲に飛び散る。体が大きくなって、はみ出すようになった |
| 比較基準 | ①内寸（cm。体長の1.5倍が目安）②入口の高さ（cm）③フチの返しの有無 |
| 外すべき人 | システムトイレ用の砂をすでに大量に買っている人（本体との組み合わせが決まります） |
| 次に困ること | 本体を変えたら、砂も合わなくなった → **P-4 猫砂** |
| 単価 | 3,000〜10,000円 |

### P-4. 猫砂

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `猫砂 飛び散らない` / `猫砂 トイレに流せる` / `猫砂 ほこり 少ない` |
| 悩みの場面 | 部屋中に砂が散る。粉っぽくてくしゃみが出る。処理方法に困っている |
| 比較基準 | ①素材（鉱物／紙／おから／木）②粒の大きさ（mm）③処理方法（可燃／流せる） |
| 外すべき人 | システムトイレを使っている人（専用の砂とシートが必要です） |
| 次に困ること | 掃除が回り始めたら、留守中の様子が気になる → **P-5 見守りカメラ** |
| 単価 | 2,000〜6,000円（**消耗品なのでリピートが最も強い**） |

### P-5. ペット見守りカメラ

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `ペットカメラ 暗い 見えない` / `ペットカメラ 月額 無料` / `見守りカメラ 録画 SDカード` |
| 悩みの場面 | 留守中の様子を見たいが、月額課金が要るのか分からない。夜間に何も見えない |
| 比較基準 | ①月額課金の要否と、無料でできる範囲 ②暗所の撮影方式（赤外線／カラーナイトビジョン）③録画先（SD／クラウド） |
| 外すべき人 | 双方向の会話をしたい人（音質は製品によって差が大きく、別の基準で選ぶ必要があります） |
| 次に困ること | 様子が見えたら、家具を引っかいているのが分かった → **P-6 爪とぎ** |
| 単価 | 4,000〜12,000円 |

### P-6. 爪とぎ

| 項目 | 内容 |
| --- | --- |
| 検索キーワード | `爪とぎ 段ボール くず` / `爪とぎ ソファ 守る` / `爪とぎ 長持ち` |
| 悩みの場面 | 段ボールのくずが散る。買ってもソファを引っかくのをやめない |
| 比較基準 | ①素材（段ボール／麻／木）②設置の向き（床置き／立て掛け／ポール）③交換の可否 |
| 外すべき人 | すでに特定の場所で研ぐ癖がついている猫（場所を変えるほうが先です） |
| 次に困ること | クラスタの終端。P-1 に戻す |
| 単価 | 2,000〜8,000円 |

## このクラスタで気をつけること

**健康・医療に踏み込まないこと。** ここが唯一のリスクです。

- ✕「腎臓病の予防になる」「尿路結石が防げる」「毛玉に効く」
- ○「水を飲む量が増えたという声が多い」「飲水量は測れる」

動物用医薬品・医薬部外品の広告規制と景品表示法の両方に関わります。
`scripts/validate.py` が「治る」「効果があります」などを検出しますが、
**病名を出した時点で危ない**ので、そもそも書かない方針にしてください。

比べるのは「手入れの手間」「音」「容量」「コスト」だけ。
健康効果は各製品の公式表示に任せて、こちらでは触れません。

**実機未使用（`stance: researched`）で書く場合**、
猫が実際に飲んだか・食べたかは評価できません。
そこは「この記事では評価していない」と明記して、
分解部品数・dB・年間コストのような**仕様で確認できることだけ**を比べてください。
