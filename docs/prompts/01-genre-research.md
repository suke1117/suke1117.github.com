# STEP1: 放置で売れ続けるジャンルを抽出する

Claude に投げるプロンプトです。そのままコピペして使えます。

最後の1行（報酬額より繰り返し検索されるジャンルを優先）を外すと、
家電やガジェットの派手なジャンルが並びます。そこは激戦区なので明示が必要です。

---

```
あなたはアマゾンの商品比較記事に詳しいリサーチャーです。

次の条件をすべて満たす商品ジャンルを15個リストアップしてください。

1. 用途が決まっていて、選ぶ基準が数値やサイズで比べられること
2. 型番が変わりにくく、1年後も同じ悩みで検索されること
3. 検索して調べる人がいるのに、まともに比べた記事が少ないこと
4. 3,000円から15,000円の価格帯で、迷って調べる程度の金額であること
5. 効果や効能を語る必要がないジャンルであること

各ジャンルについて、次を出してください。

・ジャンル名
・想定される検索キーワードを3つ
・この悩みが発生する場面
・選ぶときに比べるべき基準を3つ
・記事の冒頭で外すべき人
・同じ読者が次に困りそうなこと

表形式で出力してください。
報酬額が高いジャンルより、繰り返し検索されるジャンルを優先してください。
```

---

## 出てきたジャンルの絞り込み

出力をそのまま全部書くのではなく、次の2つで絞ります。

1. **自分が実際に買ったことがあるか** — 無いものは書けません（`own_note` が書けない）
2. **次に困りそうなことが、他のジャンルとつながるか** — 回遊（STEP4）の材料になります

「デスク環境」「キッチン」のように、**1つの場面でつながるジャンルを固めて取る**と、
記事どうしの回遊が効きます。バラバラのジャンルを1本ずつ書くと、回遊が作れません。

## 避けたほうがいいジャンル

- 健康・美容・サプリ（効果を書けないうえ、景品表示法・薬機法のリスクがある）
- 今年の新モデル系（半年で古くなり、資本のある競合と当たる）
- 1,000円以下の商品（報酬が数十円で、書く手間は1万円の商品と変わらない）
- 3万円以上の高額商品（「もう少し調べる」で離脱しやすく、実績のないサイトからは買われにくい）
