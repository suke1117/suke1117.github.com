# STEP4: 記事どうしの回遊を作る

比べ物をしている人は、1つ決めたら次の物を探し始めます。
デスク環境なら、椅子のあとにライト、そのあとにモニター台、という具合に。

記事の最後に「次に困りそうなこと」への導線を置いておくと、
検索以外の流入経路になります。

---

## 投げるプロンプト

````
次の記事の最後に置く、関連記事の案内文を作ってください。

今回の記事：[タイトルと内容の要約]
すでに公開している記事：
- [slug] [タイトル]（内容の要約）
- [slug] [タイトル]（内容の要約）

各案内について、次の形式のYAMLで出力してください。

```yaml
related:
  - slug: "[すすめる記事のslug]"
    next_trouble: "この記事を読み終えた人が、次に困りそうなこと（30字以内）"
    lead: "困りごととすすめる記事をつなぐ誘導文（80字以内）"
```

条件
・煽り表現は使わないこと
・今回の記事の内容と関係のない記事はすすめないこと
・「いま決めなくていい」という趣旨は、こちらでテンプレート側に入れてあるので不要
・1記事につき、すすめるのは1〜2本まで
````

---

## 貼り付ける場所

`data/comparisons.yml` の該当記事の `related:` を置き換えます。

```yaml
- slug: "desk-chair-cushion"
  # ...
  related:
    - slug: "zaitaku-work-starter"
      next_trouble: "座る環境を整えたあと、次に気になるのは手元の明るさ"
      lead: "座り方が落ち着いたら、次は夜の作業で目が疲れる問題が残ります。順番に整えたい人はこちら。"
```

存在しない slug を指定すると `validate.py` がエラーにします。

## 相互にリンクさせる

A→B だけでなく B→A も張ると、どちらから来た読者も次に進めます。
`comparisons.yml` の両方に `related` を書いてください。

## Pinterest

`python scripts/build_site.py` を実行すると、比較記事ごとに
`public/pin/<slug>.svg`（1000x1500）が生成されます。比較表と選ぶ基準を1枚にしたものです。

GitHub Actions では PNG にも変換されるので、
`https://<サイトのURL>/pin/<slug>.png` をダウンロードして Pinterest に投稿し、
リンク先を記事URLにしてください。ピンは消えないので、置いた分だけ残ります。
