# 注目度が高いテーマ

実機を使わずに書ける（`stance: researched`）ようになったので、
**「自分が買ったことがあるか」の制約が外れます**。ジャンルの選び方が変わるので、
[genre-candidates.md](genre-candidates.md) とは別に、需要の大きさで並べ直したものです。

---

## 先に断っておくこと

この順位は、私（Claude）の判断で並べたものです。
**実際の検索ボリュームは確認していません。**
この環境からは Amazon にもキーワードツールにもアクセスできないためです。

着手する前に、必ず次のどれかで実数を確認してください。

- Googleキーワードプランナー（無料。月間検索数の目安が出ます）
- ラッコキーワード（サジェストの網羅。無料枠あり）
- Amazonの検索窓のサジェスト（実際に買う人の言葉が出ます）

「検索ボリュームが大きいこと」と「勝てること」は別です。
下では**競合の厚さ**も併記しています。

---

## 1. ペット用品（犬・猫）

**いちばん勧めます。**

| | |
| --- | --- |
| 具体例 | 自動給水器 / 自動給餌器 / 猫トイレ・猫砂 / 爪とぎ / ペットカメラ / 消臭剤 |
| 価格帯 | 3,000〜15,000円がボリュームゾーン。条件に合う |
| 競合の厚さ | **薄い**。企業サイトはあるが、比較の粒度が粗い |
| 型番の安定 | 高い。数年単位で同じ製品が売れ続ける |
| 強み | **消耗品のリピートがある**。猫砂・フィルター・シートは繰り返し買われる |
| 弱み | 健康に踏み込むと効果効能の表現規制に触れる。「病気が治る」系は書かない |

自動給水器なら「フィルターの交換頻度」「分解して洗える部品の数」「動作音のdB」など、
**数値で比べられる軸が揃っている**のに、それを揃えて比べた記事がほとんどありません。

飼い主は同じ悩みで何度も検索します。放置が効く構造としては、この記事の趣旨に最も合います。

## 2. 季節家電の「手入れ」「静音」軸

| | |
| --- | --- |
| 具体例 | 加湿器（手入れが楽） / サーキュレーター（静音） / 衣類乾燥除湿機 / 電気毛布 |
| 価格帯 | 5,000〜15,000円。条件に合う |
| 競合の厚さ | **本体の比較は厚い。「手入れ」「静音」の軸は薄い** |
| 型番の安定 | 中。毎年モデルは出るが、基本構造は変わらない |
| 強み | 検索が季節で必ず立ち上がる。3か月前に書いておけば間に合う |
| 弱み | 大手メディアが上位を占める。真正面から「おすすめ10選」を書いても勝てない |

正面から戦わず、**軸をずらす**のがこのジャンルの入り方です。
「加湿器 おすすめ」ではなく「加湿器 手入れ 楽」「加湿器 掃除 めんどくさい」。
分解できる部品の数、フィルターの有無、食器用洗剤で洗えるかは、全部仕様で確認できます。

## 3. 子ども・学用品

| | |
| --- | --- |
| 具体例 | 水筒（食洗機対応） / 上履き洗い / ランドセルラック / 自転車ヘルメット / 入学準備 |
| 価格帯 | 3,000〜12,000円 |
| 競合の厚さ | 中。ママ向けメディアは強いが、比較の数値化は弱い |
| 型番の安定 | 高い |
| 強み | **毎年、新しい人が同じ悩みで検索する**。放置が最も効く構造 |
| 弱み | 時期が集中する（1〜3月、8月）。その時期に間に合わないと1年待ち |

「水筒 食洗機 対応」「上履き 洗うの 楽」のような検索は、毎年ゼロから発生します。
去年書いた記事が来年また読まれるという意味で、この記事が言う「放置」に最も近い塊です。

## 4. 防災用品

| | |
| --- | --- |
| 具体例 | 防災リュック / 非常用トイレ / ポータブル電源 / 給水タンク / 防災ラジオ |
| 価格帯 | 3,000〜15,000円（ポータブル電源だけ3万円超えが多い） |
| 競合の厚さ | 中 |
| 型番の安定 | 高い |
| 強み | 地震や台風のたびに検索が跳ねる。単価も比較的高い |
| 弱み | **不安を煽る表現に寄りやすい**。「これがないと危険」は書かない。効果を断定しない |

数値化しやすい（容量・持続時間・保存年数・重量）ので比較記事に向いています。
ただし、恐怖で売る書き方は規約でも景表法でも危ないので、
「何日分か」「何人分か」を淡々と並べる形に徹してください。

## 5. 掃除・水まわり

| | |
| --- | --- |
| 具体例 | 排水口の掃除 / 浴室のカビ / サッシ / レンジフード / 洗濯槽 |
| 価格帯 | **1,000〜3,000円が中心。ここが弱点** |
| 競合の厚さ | 薄い |
| 型番の安定 | 高い |
| 強み | 検索数が非常に多く、悩みが具体的 |
| 弱み | 単価が低く、報酬が数十円になりやすい |

単体では効率が悪いので、**併売狙いの入口**として使うのが現実的です。
Amazonはリンクを踏んだ人が24時間以内に買った他の商品も成果になるため、
検索数の多い低単価ジャンルを入口にする戦い方は成立します。

## 6. デスク環境（既存のクラスタA）

[genre-candidates.md](genre-candidates.md) のクラスタA。
需要では上位ジャンルに劣りますが、**回遊が5本一直線につながる**という利点があります。
すでに骨組みを書いてあるので、着手コストは最小です。

## 避けたほうがいいテーマ

| テーマ | 理由 |
| --- | --- |
| スマホ周辺（充電器・モバイルバッテリー・ケース） | 検索数は最大級だが競合が最も厚く、型番が半年で変わる |
| イヤホン・スマートウォッチ | 大手メディアとレビュアーが占有。新製品サイクルが速い |
| 健康・美容・サプリ | 効果効能の表現規制。比較記事の形にしにくい |
| ロボット掃除機・ドライヤー | 単価3万円超が中心。実績のないサイトからは買われにくい |
| 食品・日用品の消耗品 | 単価が低すぎる。ただし併売の受け皿としては優秀 |

## 現実的な組み立て方

1本目から需要の大きいジャンルに行くより、**軸をずらせるジャンルから入る**ほうが安全です。

| 順番 | 選び方 |
| --- | --- |
| 1〜3本目 | 競合が薄いジャンル（ペット用品 / 子ども学用品）で、比較表の作り方に慣れる |
| 4〜10本目 | 同じクラスタ内を埋めて回遊をつなぐ |
| 11本目以降 | 季節家電など需要の大きいジャンルに、軸をずらして入る |

`stance: researched` で書く場合、**勝負どころはレビューの読み込みです。**
★1〜2を30件以上読んで同じ不満を数える、仕様表の測定条件を揃える。
この2つは競合サイトがやっていないことが多く、実機がなくても差がつきます。
