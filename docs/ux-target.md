# UIの設計方針

## ターゲット

**猫と暮らして1〜3年の人が、具体的な不満を1つ抱えて調べている場面。**

| | |
| --- | --- |
| デバイス | **スマートフォン（縦持ち・片手）が9割** |
| 時間帯 | 夜21〜24時。1日の家事が終わったあと |
| 姿勢 | ソファやベッド。猫が膝や横にいることが多い |
| 使える時間 | **細切れの3〜10分**。まとまった時間ではない |
| 状態 | 「掃除が面倒」「砂が散る」「留守が不安」など、**不満が具体的に1つある** |
| ゴール | 「自分の場合はどれか」を決める。全商品を理解したいわけではない |

## この人が困ること

一般的な比較記事を、この状況で読むと次が起きます。

1. **前置きが長い**。「そもそも自動給水器とは」から始まって、本題に届かない
2. **横スクロールの比較表が読めない**。スマホで表を横に振るのは片手では無理
3. **どこを読めばいいか分からない**。8つの見出しがあっても、自分に関係あるのは1つ
4. **結局どれか分からない**。全部おすすめと書いてあって、選べない

## 設計の原則

### 1. 最初の1タップで、自分の話に飛べる

記事の冒頭に「あなたの状況は？」を置き、タップすると該当商品まで飛びます。
最後まで読ませることを目的にしません。**答えに最短で着くことを優先します。**

飛んだ先はハイライトされるので、どこに来たかが分かります。

### 2. 比較表を横スクロールさせない

スマホ幅では表をカードに組み替えます。1商品＝1カードで、縦にスクロールするだけで読めます。
数値の列は、その記事の基準で有利な値に印を付けます（例：分解部品が最少）。

### 3. いまどこを読んでいるかが常に分かる

上部に固定したタブで、記事の8セクションを行き来できます。
スクロールに応じて現在地がハイライトされます。読み飛ばしを前提にした構造です。

### 4. 片手で操作できる

- タップ領域は最小44px
- 主要な操作は画面下寄りにも配置（上に戻るボタン）
- 横スクロールが必要な要素は、タブとコードブロックだけに限定

### 5. 夜に読まれる

ダークモードを既定で尊重します。白い画面をそのまま出しません。
背景は純白・純黒を避け、目に刺さらない値にします。

## やらないこと

- **ポップアップ・追従バナー・カウントダウン** … 買わせるための演出は入れません
- **自動再生の動画** … 夜間・電車内で音が出る事故を避けます
- **無限スクロール** … 記事の終わりが分かるほうが、判断しやすいためです
- **重いWebフォント** … 日本語フォントは1MB超になります。端末のフォントを使います
